NODWISE
A Smart ML Framework for Continuous Head Movement Awareness

NODWISE is a Machine Learning and Computer Vision based posture monitoring system designed to detect poor neck posture and prolonged static head movement in real time using a webcam. The project aims to reduce neck strain, cervical stress, and posture-related health issues caused by prolonged screen usage.

This repository contains the complete implementation of the NODWISE research project, including:

real-time posture detection
neck angle analysis
temporal movement tracking
static posture detection
dashboard UI
research result visualization
graph generation modules
Purpose of This Repository

The main purpose of this repository is to provide a practical implementation of an intelligent ergonomic monitoring system capable of:

Monitoring neck posture continuously
Detecting unhealthy head positions
Tracking prolonged inactivity
Generating real-time posture alerts
Improving posture awareness among users

The repository also serves as:

an academic research implementation
a demonstration project for posture analysis
a computer vision and machine learning learning resource
a base framework for future ergonomic health applications
Problem Statement

With the increasing use of laptops, smartphones, and desktop systems, people often maintain poor posture for long durations, resulting in:

neck pain
cervical strain
forward head posture
reduced mobility
musculoskeletal disorders

Traditional posture correction systems often require:

wearable sensors
expensive hardware
intrusive monitoring systems

NODWISE solves this problem using only:

a webcam
computer vision
machine learning based posture analysis

making the solution:

low-cost
contactless
accessible
real-time
